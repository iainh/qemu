SiFli SF32LB52 (``sf32lb52``)
================================

The ``sf32lb52`` machine models the HCPU side of the SiFli SF32LB52
microcontroller. It is intended for PebbleOS firmware bring-up and uses the
hardware memory map and interrupt numbers.

Supported devices
-----------------

The machine provides:

- Cortex-M33 HCPU with 96 external interrupts and 3 priority bits
- HPSYS and LPSYS SRAM
- external flash with persistent image backing and the PebbleOS slot 0
  vector-table alias
- DWT cycle counter
- startup clock, eFuse, TRNG, watchdog, I2C reset, audio PLL calibration, and
  MPI flash handshakes
- running RTC calendar and alarm plus LPTIM1 low-power wake timer
- interrupt-driven I2C controllers with generic register-backed slave storage
- Obelix I2C device identities and ready states for its touch, motion,
  compass, backlight, and ambient-light drivers
- DMAC transfer completion and DMA-backed external flash page programming
- 4 KiB sector and 32/64 KiB block erase commands
- LCDC1 JDI transfers to the 200x228 RGB332 Obelix display
- Obelix buttons through GPIO1 and touchscreen events through the CST816
- circular speaker and microphone DMA with generated microphone samples
- generated stationary LSM6DSO FIFO samples and watermark interrupts
- an HCPU/LCPU mailbox transport with a minimal Bluetooth LE HCI controller
- USART1 connected to the first QEMU serial backend

Bluetooth radio links, host audio input/output, DMA data movement outside the
modelled flash and audio paths, and most peripherals are not implemented.
Unimplemented peripheral registers retain their values to support incremental
firmware bring-up.

Booting PebbleOS
----------------

Build PebbleOS for an SF32LB52 board, then pass the ELF directly to QEMU. For
example:

.. code-block:: shell

  qemu-system-arm -M sf32lb52 -display none \
      -serial stdio -kernel build/pebbleos.elf \
      -drive if=mtd,format=raw,file=obelix-resources.bin

The machine aliases the slot 0 vector table at external flash offset
``0x21000`` to address zero for reset.

The optional MTD image initializes the external flash and receives guest
program and erase operations. Use a 32 MiB image to back the complete
GD25Q256E address space, including the Pebble filesystem near the end of the
device. Bytes beyond a shorter image remain erased and are not persisted.
