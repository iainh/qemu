SiFli SF32LB52 (``sf32lb52``)
================================

The ``sf32lb52`` machine models the HCPU side of the SiFli SF32LB52
microcontroller. It is intended for PebbleOS firmware bring-up and uses the
hardware memory map and interrupt numbers.

Supported devices
-----------------

The machine provides:

- Cortex-M33 HCPU with 96 external interrupts and 3 priority bits
- HPSYS and LPSYS SRAM
- external flash with the PebbleOS slot 0 vector-table alias
- DWT cycle counter
- startup clock, eFuse, RTC, TRNG, and basic MPI flash handshakes
- USART1 connected to the first QEMU serial backend

The LCPU, Bluetooth, display, DMA, and most peripherals are not implemented.
Unimplemented peripheral registers retain their values to support incremental
firmware bring-up.

Booting PebbleOS
----------------

Build PebbleOS for an SF32LB52 board, then pass the ELF directly to QEMU. For
example:

.. code-block:: shell

  qemu-system-arm -M sf32lb52 -display none \
      -serial stdio -kernel build/pebbleos.elf

The machine aliases the slot 0 vector table at external flash offset
``0x21000`` to address zero for reset.
